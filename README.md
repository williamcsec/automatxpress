# AutomatXpress Website

AutomatXpress is a modern web application built with [Next.js](https://nextjs.org/).

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework:** Next.js
- **UI & Styling:** Tailwind CSS
- **3D Graphics:** Spline
- **Language:** TypeScript
